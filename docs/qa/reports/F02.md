Changed behavior:

- `server/server.js`: deleted the catch-all cache predicate (`['/', ...].some(p => req.path.startsWith(p))` — proven in-test to match EVERY path via `'/'`, which made the production `immutable` branch below it dead code) and the manual chat-asset `Content-Type` override (which mislabelled every font `font/woff2`; MIME now left to `express.static`/`send`, verified per extension). Security headers (`X-Content-Type-Options`, chat-scoped `X-Frame-Options` skip, `Referrer-Policy`), the `/chat/` CSP `frame-ancestors *` middleware, and request logging are byte-identical and untouched.
- New `server/middleware/webAssetCache.js` (pure `classifyWebAssetCache(pathname)` + `webAssetCache` middleware, mounted in the same position): HTML page prefixes (exact/boundary — `'/'` matches itself only) + `.html` → no-store trio; `/api*` sensitive → no-store trio; `/health*` liveness → no-store trio (preserves old effective no-store so readiness is never heuristically cached); `/service-worker.js` exact → `Cache-Control: no-cache` (revalidate; never no-store/immutable); all other css/js/woff/woff2/ttf → `no-cache` in EVERY environment (prod `immutable` removed — query `?v=` is query-blind by construction since Express strips it from `req.path`); chat-embedded static (path contains `/chat`) stays no-store; png/jpg/jpeg/gif/ico/json keep `public, max-age=300`; everything else passes through headerless (static files still get send's safe `public, max-age=0` default; sitemap/robots/auth route-level headers overwrite downstream as before).
- Deliberate, reviewed deltas: (a) prod `immutable` on unversioned JS/CSS is GONE by design (it was unreachable under the catch-all and wrong for non-fingerprinted URLs); (b) dynamic non-API error responses (404 HTML/JSON) no longer get middleware no-store — they get send's `max-age=0` (static 404 page) or no header (JSON); `errorHandler.js` is D06-owned and untouched — D06/A06 may add explicit policy there if desired. No proxy/Coolify changes.
