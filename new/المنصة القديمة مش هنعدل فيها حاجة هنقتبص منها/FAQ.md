## 🌟 عامة

### س: ما هي Zain AI؟

**ج:** Zain AI هي منصة مفتوحة المصدر لإدارة البوتات الذكية التي تستخدم الذكاء الاصطناعي من OpenAI للرد على العملاء عبر قنوات متعددة (Facebook, WhatsApp, Instagram, Web).

### س: هل المنصة مجانية؟

**ج:** نعم، الكود مفتوح المصدر (MIT License) ويمكنك استخدامه مجاناً. لكن ستحتاج:
- OpenAI API Key (مدفوع حسب الاستخدام)
- MongoDB (مجاني في Atlas)
- استضافة (مجانية في Render/Heroku أو مدفوعة)

### س: ما الفرق بين Zain AI وChatGPT؟

**ج:**
- **ChatGPT:** منصة محادثة عامة
- **Zain AI:** منصة لإنشاء بوتات مخصصة بميزات:
  - ربط بقنوات خارجية (WhatsApp, Facebook)
  - ربط بمتاجر إلكترونية
  - استخراج طلبات وأرقام
  - تخصيص كامل للردود

### س: هل يمكنني استخدامها لأغراض تجارية؟

**ج:** نعم، الترخيص (MIT) يسمح بالاستخدام التجاري بدون قيود.

## ⚙️ التثبيت والإعداد

### س: ما هي المتطلبات لتشغيل المنصة؟

**ج:**
- **Node.js** v18 أو أحدث
- **MongoDB** (محلي أو Atlas)
- **npm** v9+
- **(اختياري)** OpenAI API Key

### س: هل يعمل على Windows/Mac/Linux؟

**ج:** نعم، يعمل على جميع الأنظمة التي تدعم Node.js.

### س: لماذا npm install يستغرق وقتاً طويلاً؟

**ج:** أول مرة يحتاج تحميل اعتماديات كثيرة (~200MB). استخدم:
```bash
npm install --prefer-offline
```

### س: كيف أحل مشكلة MongoDB connection failed؟

**ج:** راجع [دليل حل المشاكل](TROUBLESHOOTING.md#-مشاكل-قاعدة-البيانات).

## 🤖 البوتات

### س: كم بوت يمكنني إنشاء؟

**ج:** لا يوجد حد! يمكنك إنشاء بوتات غير محدودة لكل مستخدم.

### س: هل يمكن ربط بوت واحد بعدة قنوات؟

**ج:** نعم، كل بوت يمكنه الاتصال بـ:
- Facebook Messenger
- WhatsApp
- Instagram DM
- Telegram
- Web Chat

### س: كيف أوقف بوت مؤقتاً؟

**ج:** من لوحة التحكم → إعدادات البوت → غيّر `isActive` إلى `false`.

### س: ما الفرق بين القواعد (Rules) والذكاء الاصطناعي؟

**ج:**
- **القواعد:** ردود ثابتة على كلمات مفتاحية (أسرع، لا تحتاج OpenAI)
- **الذكاء الاصطناعي:** ردود ديناميكية ذكية (تحتاج OpenAI، أغلى)

البوت يفحص القواعد أولاً، لو ما لقى يستخدم AI.

### س: كيف أجعل البوت يتذكر المحادثات؟

**ج:** المنصة تحفظ آخر 10-20 رسالة تلقائياً في `Conversation` model.

## 🧠 الذكاء الاصطناعي

### س: هل أحتاج OpenAI API Key حتماً؟

**ج:** لا، لكن بدونه:
- البوت سيعتمد فقط على **القواعد (Rules)**
- لن يرد على أسئلة غير متوقعة

يمكنك البدء بدون OpenAI واختباره بالقواعد فقط.

### س: كم تكلفة OpenAI API؟

**ج:** (تحديث 2026)
- **gpt-4o-mini:** $0.15 لكل مليون token input، $0.60 output
- **مثال:** 1000 محادثة = ~$1-2

راجع [OpenAI Pricing](https://openai.com/api/pricing/).

### س: هل يمكن استخدام AI آخر غير OpenAI؟

**ج:** نعم! يمكنك تعديل `botEngine.js` لاستخدام:
- Google Gemini
- Anthropic Claude
- Llama (محلي)
- Cohere

تحتاج تعديل كود (`openai.chat.completions.create()`).

### س: لماذا البوت يرد ببطء؟

**ج:** OpenAI API قد يأخذ 2-5 ثوانٍ حسب:
- الـ model المستخدم
- طول المحادثة
- سرعة الإنترنت

**حل:** استخدم `gpt-4o-mini` بدلاً من `gpt-4` (أسرع وأرخص).

### س: كيف أخصص شخصية البوت؟

**ج:** عدّل الـ **System Prompt** في `botEngine.js`:

```javascript
const systemPrompt = `
أنت بوت خدمة عملاء محترف ومهذب.
تتحدث باللغة العربية بطلاقة.
تخصصك: [اذكر مجالك]
أسلوبك: [ودود/جاد/فكاهي]
`;
```

## 🔗 القنوات الخارجية

### س: كيف أربط Facebook Messenger؟

**ج:** راجع [دليل البدء السريع](QUICK_START.md#facebook-messenger-متقدم) للخطوات التفصيلية.

**ملخص:**
1. أنشئ Facebook App
2. أضف Messenger Product
3. احصل على Page Access Token
4. اضبط Webhook URL
5. أدخل التوكن في البوت

### س: هل يمكن ربط WhatsApp بدون WhatsApp Business API؟

**ج:** نعم! استخدم **تطبيق WazainBot** (Electron):
```bash
cd wazainbot
npm install
npm start
```

يربط WhatsApp Web مباشرة عبر QR Code.

### س: Webhook verification يفشل دائماً، ما الحل؟

**ج:**
1. **Verify Token يجب أن يكون:** `hassanshehata`
2. **الـ URL يجب أن يكون HTTPS** (استخدم ngrok لو محلي)
3. **تحقق من Endpoint:**
```bash
curl "https://your-domain.com/api/webhook/facebook?hub.mode=subscribe&hub.verify_token=hassanshehata&hub.challenge=test"
# يجب أن يرجع: test
```

### س: هل يمكن ربط بوت واحد بعدة صفحات فيسبوك؟

**ج:** لا، كل بوت يربط بـ Page واحد. لربط عدة صفحات، أنشئ بوتات منفصلة.

### س: Instagram Webhooks لا تعمل، ما السبب؟

**ج:**
- تأكد أن الحساب **Business** (ليس Personal)
- تأكد من ربطه بـ Facebook Page
- Tokens Instagram تنتهي بسرعة، تأكد من التجديد التلقائي

## 🏪 المتاجر

### س: كيف أنشئ متجر إلكتروني؟

**ج:**
1. لوحة التحكم → **إدارة المتاجر**
2. **إنشاء متجر جديد**
3. أدخل الاسم والرابط
4. **أضف منتجات** من صفحة المتجر
5. **اربط البوت** بالمتجر

### س: كم متجر يمكنني إنشاء؟

**ج:** غير محدود.

### س: هل يمكن للبوت استقبال طلبات؟

**ج:** نعم! البوت يستخدم AI لاستخراج:
- المنتجات المطلوبة
- الكمية
- رقم الهاتف
- العنوان

ثم يحفظها في **Chat Orders**.

### س: كيف أغير تصميم المتجر؟

**ج:** المنصة توفر 5 قوالب جاهزة:
- `template1` - `template5`

في إعدادات المتجر → **Template**.

### س: هل يمكن ربط دفع إلكتروني؟

**ج:** حالياً لا، لكن يمكنك إضافته بتعديل الكود:
- Stripe
- PayPal
- Paymob (مصر)

## 🔐 الأمان

### س: هل البيانات آمنة؟

**ج:** نعم، المنصة تستخدم:
- **JWT Authentication**
- **bcrypt Password Hashing**
- **Helmet.js** للحماية من XSS/CSRF
- **Rate Limiting** ضد الهجمات
- **HTTPS** في الإنتاج

### س: أين تُخزن البيانات؟

**ج:**
- **قاعدة البيانات:** MongoDB (على سيرفرك أو Atlas)
- **الملفات:** مجلد `uploads/` على السيرفر

### س: كيف أحمي API Keys؟

**ج:**
- **لا تضعها في الكود أبداً**
- استخدم `.env` دائماً
- أضف `.env` لـ `.gitignore`
- في الإنتاج، استخدم Environment Variables

### س: كيف أبلغ عن ثغرة أمنية؟

**ج:** راجع [سياسة الأمان](SECURITY.md).

**⚠️ لا تفتح Issue عامة!**

أرسل لـ: security@zain-ai.com
