## 🎯 المميزات الأساسية

### 🤖 إدارة البوتات المتقدمة

#### ✅ إنشاء وإدارة بوتات غير محدودة
- إنشاء عدد لا نهائي من البوتات لكل مستخدم
- كل بوت مستقل بإعداداته الخاصة
- تنظيم البوتات في واجهة واحدة

#### ✅ نظام اشتراكات مرن
- **Free:** بوت تجريبي
- **Monthly:** اشتراك شهري
- **Yearly:** اشتراك سنوي
- إيقاف تلقائي عند انتهاء الاشتراك
- إشعارات قبل انتهاء الصلاحية

#### ✅ قواعد ذكية (Rules System)
- إنشاء قواعد مخصصة لكل بوت
- ردود فورية على كلمات مفتاحية
- أولوية القواعد قبل الذكاء الاصطناعي
- توفير في تكلفة OpenAI API

#### ✅ رسائل ترحيب قابلة للتخصيص
- رسالة ترحيب مخصصة لكل بوت
- تفعيل/تعطيل حسب القناة
- دعم المتغيرات (اسم المستخدم، الوقت، إلخ)

#### ✅ التحكم في حالة البوت
- تشغيل/إيقاف فوري
- جدولة الإيقاف التلقائي
- إيقاف مؤقت (Mute) لفترة محددة

## 🧠 الذكاء الاصطناعي

### 🚀 تكامل OpenAI متقدم

#### ✅ نماذج متعددة
- **gpt-4o-mini:** للمحادثات النصية (سريع واقتصادي)
- **gpt-4.1-nano-2025-04-14:** لتحليل الصور
- إمكانية التبديل بين النماذج

#### ✅ معالجة محتوى متعدد
- **نصوص:** ردود ذكية ومحادثة طبيعية
- **صور:** تحليل ووصف الصور
- **صوت:** تحويل إلى نص (عبر LemonFox API) ثم الرد

#### ✅ ذاكرة محادثة ذكية
- حفظ سياق المحادثة (10-20 رسالة سابقة)
- تتبع موضوع الحوار
- فهم الأسئلة المرتبطة

#### ✅ استخراج النوايا (Intent Extraction)
- **أرقام الهواتف:** تلقائياً
- **عناوين:** استخراج العناوين من النص
- **طلبات:** تحديد المنتجات والكميات
- **استفسارات:** فهم نوع السؤال

#### ✅ ربط بالمتجر
- الوصول لبيانات المنتجات
- الرد على استفسارات الأسعار والتوفر
- اقتراح منتجات مشابهة

## 🔗 القنوات والتكاملات

### 📱 دعم متعدد القنوات

#### ✅ Facebook Messenger
- استقبال وإرسال رسائل فورية
- دعم الـ Webhooks الكامل
- معالجة:
  - النصوص
  - الصور
  - الملفات
  - Reactions
  - Postbacks
- تجديد تلقائي للتوكينات
- معالجة التعليقات على المنشورات

#### ✅ WhatsApp Business API
- دعم كامل للرسائل
- معالجة:
  - النصوص
  - الصور
  - الصوت
  - المستندات
  - الموقع
- Webhooks آمن
- حالات القراءة والتسليم

#### ✅ Instagram Direct Messages
- رسائل مباشرة
- تعليقات على المنشورات
- Stories Mentions
- تجديد تلقائي للتوكينات

#### ✅ Telegram Bot
- إشعارات للطلبات الجديدة
- تحديثات حالة الطلبات
- ملخص يومي
- دعم متعدد اللغات (عربي/إنجليزي)
- ربط بكود مؤقت

#### ✅ Web Chat
- صفحة شات مخصصة لكل بوت
- تصميم responsive
- تجربة مستخدم سلسة
- إمكانية التضمين في أي موقع

### 🖥️ تطبيق سطح المكتب (WazainBot)

#### ✅ ربط WhatsApp Web محلي
- بديل لـ WhatsApp Business API
- مسح QR Code مباشر
- لا حاجة لـ API keys

#### ✅ إدارة متعددة
- إدارة بوتات متعددة من جهاز واحد
- تبديل سريع بين البوتات

#### ✅ حفظ الجلسات
- تخزين محلي في `%APPDATA%`
- لا حاجة لإعادة مسح QR
- استعادة تلقائية بعد إعادة التشغيل

#### ✅ واجهة سهلة
- QR Code واضح
- حالة الاتصال مباشرة
- عداد الرسائل الواردة
- فتح لوحة التحكم بنقرة

## 🏪 إدارة المتاجر

### 🛍️ نظام متاجر إلكترونية متكامل

#### ✅ إنشاء متاجر غير محدودة
- متجر لكل بوت
- إعدادات مستقلة لكل متجر

#### ✅ إدارة المنتجات
- إضافة/تعديل/حذف منتجات
- صور متعددة للمنتج
- تصنيفات (Categories)
- إدارة المخزون (Stock)
- تنبيهات المخزون المنخفض
- كود SKU فريد

#### ✅ قوالب تصميم متعددة
- **5 قوالب جاهزة:**
  - Template 1: كلاسيكي
  - Template 2: عصري
  - Template 3: أنيق
  - Template 4: بسيط
  - Template 5: ديناميكي
- تبديل فوري بين القوالب
- ألوان قابلة للتخصيص

#### ✅ لاندينج بيج لكل متجر
- صفحة هبوط احترافية
- عرض المنتجات المميزة
- معلومات الاتصال
- روابط التواصل الاجتماعي

#### ✅ روابط مخصصة
- كل متجر له رابط فريد:
  ```
  https://your-domain.com/store/my-store-link
  ```

## 🔐 الأمان

### 🛡️ حماية متعددة الطبقات

#### ✅ مصادقة قوية
- **JWT Authentication:** توكينات مشفرة
- **bcrypt:** تشفير كلمات المرور (10 rounds)
- **Google OAuth:** تسجيل دخول آمن

#### ✅ نظام أدوار
- **User:** مستخدم عادي (بوتاته فقط)
- **SuperAdmin:** وصول كامل

#### ✅ Rate Limiting متقدم
- **حد عام:** 300 طلب / 15 دقيقة
- **حد مصادقة:** 7 طلبات / 15 دقيقة
- **حد Webhooks:** 60 طلب / دقيقة
- حماية من DDoS

#### ✅ Helmet.js
- Content Security Policy (CSP)
- XSS Protection
- Frame Protection
- HTTPS Enforcement

#### ✅ تحقق من البريد الإلكتروني
- رسالة تحقق مع رابط
- رفض Gmail بدون Google OAuth
- انتهاء صلاحية الرابط

#### ✅ Webhook Verification
- التحقق من Signature
- Verify Token ثابت: `hassanshehata`
- رفض الطلبات المزيفة

#### ✅ منع الرسائل المكررة
- NodeCache للتتبع
- TTL: 5 دقائق
- فحص Message ID

## 👨‍💻 تجربة المطور

### 🔧 معمارية نظيفة

#### ✅ MVC Pattern
- Models في `server/models/`
- Controllers في `server/controllers/`
- Routes في `server/routes/`
- فصل واضح للمسؤوليات

#### ✅ كود منظم
- أسماء واضحة
- تعليقات بالعربية
- ESLint ready
- معايير موحدة

#### ✅ Error Handling شامل
- try/catch في كل async function
- معالجة أخطاء مركزية
- رسائل خطأ واضحة

### 📝 Logging متقدم

#### ✅ Winston Logger
- مستويات متعددة: info, warn, error
- ملفات منفصلة
- تنسيق JSON
- Rotation تلقائي

#### ✅ تنظيف تلقائي
- حذف لوجز أقدم من 30 يوم
- Cron Job أسبوعي

### ⏰ Cron Jobs

#### ✅ مهام مجدولة
- فحص البوتات المنتهية (يومياً 12 صباحاً)
- تجديد توكينات (يومياً 2 صباحاً)
- تنبيهات المخزون (يومياً 8 صباحاً)
- تنظيف اللوجز (أسبوعياً)

### 🧪 Testing

- اختبار APIs
